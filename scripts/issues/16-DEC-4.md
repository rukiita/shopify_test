### Question
Should tags added or removed in the app be written to the Shopify order, or kept only in the app database? The task does not say.

### Options
1. Write to Shopify with `tagsAdd` / `tagsRemove` and receive the result via webhook
2. Keep an app-specific tag table separate from Shopify's tags
3. Update only the `tags` column in the app database

### Findings
- Option 3 is reverted to Shopify's tags whenever `orders/updated` arrives
- Option 1 requires the `write_orders` scope

### After deciding
Remove the conditional wording from #3, #4 and #19 so their acceptance criteria and scopes match the decision.
