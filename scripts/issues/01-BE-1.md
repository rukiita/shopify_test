### Task description
> Create/update orders to app database base on Store webhook

### Interpretation
- Subscribe to `orders/create` and `orders/updated` (declared only in `shopify.app.toml`)
- Verify the HMAC signature. Use the webhook only as a trigger and refetch the order via GraphQL (ADR-0003)
- Overwrite only when the fetched `updatedAt` is newer than the stored one (out-of-order deliveries must not overwrite newer data)
- Receiving the same webhook more than once has the same result (idempotent)

### Acceptance criteria
- [ ] Creating a test order creates an Order and its LineItems in the database
- [ ] Editing an order (tags, address, etc.) is reflected in the database
- [ ] Requests with an invalid signature return 401
- [ ] Sending the same payload twice creates no duplicates
- [ ] Data with an older `updatedAt` does not overwrite newer data
- [ ] `app/uninstalled` deletes the shop's data

### Before starting (spike)
- [ ] Call the order query against the development store and save the responses under `test/fixtures/` (regular order / no customer / line item with `product: null`). Do not keep the throwaway code
