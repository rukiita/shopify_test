### Question
The task prefers "Node.js or Remix", while Shopify now recommends its React Router v7 template as the successor to Remix. Which should the app be built on?

### Options
1. React Router v7 template (`shopify-app-template-react-router`)
2. Remix template (`shopify-app-template-remix`)
3. Plain Node.js (e.g. Express) from scratch

### Findings
- The Remix template README states that Remix has merged into React Router v7 and directs new projects to the React Router template https://github.com/Shopify/shopify-app-template-remix
- Migration guide: support for the Remix package is limited to critical security fixes https://github.com/Shopify/shopify-app-template-react-router/wiki/Upgrading-from-Remix
