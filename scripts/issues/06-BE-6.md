### Task description
> Need some fields not in order/id/.json
> - Product title
> - Product tags

### Interpretation
- Product tags are not part of the order data, so the product must be fetched
- The GraphQL query that refetches the order also selects `lineItems { product { id title tags } }` (ADR-0003)
- Whether the title is the one at purchase time or the current one, and how fresh product tags must be, is decided in DEC-6 (#18)
- Line items for deleted or custom products have `product: null`
- Outputting these fields as CSV columns is part of BE-5 (#5)

### Acceptance criteria
- [ ] Ingesting an order stores the product title and tags
- [ ] Line items with `product: null` do not break ingestion
