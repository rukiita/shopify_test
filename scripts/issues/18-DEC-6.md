- **CSV row granularity**: one row per line item (order columns repeated) / one row per order (products combined in one cell)
- **Product title**: title at purchase time (`LineItem.title`) / current title (`Product.title`)
- **Product tag freshness**: values at ingestion time / kept current by subscribing to `products/update`
- **Customer address**: shipping (`shippingAddress`) / billing (`billingAddress`)
- **CSV format**: separator for multi-value fields, date format (ISO 8601 / shop time zone), whether to add a BOM
