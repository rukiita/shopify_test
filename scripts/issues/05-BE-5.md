### Task description
> Allow merchants to export orders to a CSV file. Ensure that the exported CSV file includes relevant order information such as order number, customer details, product details.
>
> CSV template: Order id / Order number / Total price / Payment gateway / Customer email / Customer full name / Customer address / Tags / Created at

### Interpretation
- Row granularity (per line item or per order), date format and whether to add a BOM are decided in DEC-6 (#18)
- Escape per RFC 4180 (values containing `,`, `"` or line breaks)
- Built from the database (no Shopify API calls at export time)
- Also outputs Product title / Product tags (the values are fetched and stored by BE-6 #6)

### Acceptance criteria
- [ ] A CSV file can be downloaded from a button in the app (inside the embedded admin)
- [ ] Column order matches the CSV template, followed by Product title / Product tags
- [ ] Values containing commas, quotes or line breaks do not shift columns
- [ ] Opens without garbled characters in Excel / Numbers
