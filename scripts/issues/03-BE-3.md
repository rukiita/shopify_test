### Task description
> Allow merchants to add tag to an order

### Interpretation
- Trim surrounding whitespace. Reject empty strings and tags that already exist
- Where tags are written is decided in ADR-0004 (#16). Proposal: write to Shopify with `tagsAdd`

### Acceptance criteria
- [ ] A tag can be added from the list
- [ ] Empty and duplicate tags are rejected with a reason shown
- [ ] The button is disabled while saving
- [ ] An error is shown on failure
- [ ] (If ADR-0004 writes to Shopify) the tag appears in the Shopify admin

### Test list (top to bottom: Red → Green → Refactor)
- [ ] `BE-3 Add tag : 1. trims surrounding whitespace` (normalize-tag)
- [ ] `BE-3 Add tag : 1. rejects an empty tag`
- [ ] `BE-3 Add tag : 1. rejects a tag that already exists`
- [ ] `BE-3 Add tag : 1. rejects a tag over the maximum length`
- [ ] `BE-3 Add tag : 1. calls tagsAdd and updates the stored tags` (action; admin.graphql mocked)
- [ ] `BE-3 Add tag : 1. returns an error and leaves the database unchanged on userErrors`
