### Task description
> Create user-friendly interface that displays list of orders

### Interpretation
- Columns are decided in DEC-6 (#18). Proposal: order number / created at / customer name / email / total / payment gateway / tags
- Data is read from the database (no Shopify API call on each page view)
- Newest first, cursor-based pagination

### Acceptance criteria
- [ ] The list matches the orders in the development store
- [ ] Pagination works
- [ ] With no orders, an empty state points to the sync button
- [ ] Loading and error states are visible

### Test list (top to bottom: Red → Green → Refactor)

- [ ] `BE-2 Order list : 1. excludes orders from other shops`
