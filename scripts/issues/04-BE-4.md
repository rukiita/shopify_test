### Task description
> Allow merchants to … remove tag from an order

### Interpretation
- Where tags are written is decided in ADR-0004 (#16). Proposal: write to Shopify with `tagsRemove`
- The `orders/updated` that arrives right after removal must not bring the tag back

### Acceptance criteria
- [ ] Each tag can be removed with its remove button
- [ ] The button is disabled while saving
- [ ] On failure an error is shown and the tag remains
- [ ] (If ADR-0004 writes to Shopify) the tag disappears from the Shopify admin

### Test list (top to bottom: Red → Green → Refactor)
- [ ] `BE-4 Remove tag : 1. calls tagsRemove and updates the stored tags` (action; admin.graphql mocked)
- [ ] `BE-4 Remove tag : 1. returns an error and keeps the tag on userErrors`
- [ ] `BE-4 Remove tag : 1. rejects removing a tag that does not exist`
